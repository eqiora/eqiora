# Legacy MSH observation encodings

These files were generated by the unchanged production code at commit
`2144643b152f7ccdc4b7c79bea43f79d2796eeda`, reconstructed with `git archive`.
The probe used the original `AuthenticatedCommonMesh::gmsh_4152` constructor
with an authored square MSH fixture and wrote `to_bytes()` and the production
lineage's `canonical_json()`. These bytes test old encodings; they are not
proof of a Gmsh executable run or numerical oracle values.

The second common Mesh fixture has a 3-by-3 square grid (18 triangles and 12
boundary facets) and the old Gmsh facet-policy value of eight. Its acceptance
records the old planar replay behavior. External import enforces its own facet
limit; it must not change the interpretation of this old occurrence.

Generation command, using a temporary example added only to the archived tree:

```sh
ARCHIVE_OUTPUT=<this directory> cargo run --locked -p eqiora-numerics --example archive_msh_v4
```

Copy the adjacent `generate_legacy.rs` probe into the archived tree at
`crates/eqiora-numerics/examples/archive_msh_v4.rs` before running the command.
The source snapshot and full generation log are retained in the task's
home-backed `msh-import` validation cache. Tests require byte-for-byte canonical
round trips through both original schema kinds, including omitted fields and
field order. New external-import kinds are not claimed readable by old code.
