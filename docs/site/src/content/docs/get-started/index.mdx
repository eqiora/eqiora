Run a small model, then change it and see the difference. You need two files and
a Python environment. The example below works with the published Eqiora `0.1.2`
package; no source checkout, Rust compiler, mesh generator or editor extension is needed.

## Install with uv

Prebuilt wheels support **Linux x86-64** and ordinary-GIL **CPython 3.11–3.14**.
These commands select CPython 3.13. Install
[uv](https://docs.astral.sh/uv/getting-started/installation/) if you do not have it,
then create a project:

```bash
uv init --python 3.13 first-eqiora-model
cd first-eqiora-model
uv add eqiora
```

In an existing uv project, just run `uv add eqiora`. This installs the published
package from PyPI and records the dependency in `pyproject.toml` and `uv.lock`.
Use `uv add eqiora==0.1.2` if you want to select the release used for this walkthrough
explicitly. Keep the lockfile with your project to reproduce its environment.

Save the following files in the project folder, beside `pyproject.toml`.
No shell activation is needed: `uv run` uses the project's environment.
Lessons that run repository scripts use the optional [example files](#example-files).
Downloading those files does not require rebuilding Eqiora.

## Predict the result

Let a dimensionless quantity $x$ start at 1 and decay at rate
$k=1\,\mathrm{s}^{-1}$:

$$
\frac{\mathrm{d}x}{\mathrm{d}t}+kx=0,\qquad x(0)=1.
$$

The solution is $x(t)=\exp(-kt)$. After one second, predict
$x(1)=\exp(-1)\approx0.367879$—about 37% of the initial value.

with two ordered sides of an equality. The numerical method does not belong in this file.

The script compiles `decay.eqi`, chooses an adaptive time method, starts from the
model's initial state and requests three observations. The returned `Result`
contains a time series selected by the model's field handle. The two NumPy arrays
hold times in seconds and the corresponding dimensionless values.

## Run and inspect

```bash
uv run python run.py
```

You should see values close to:

```text
t=0.25, x=0.7788007829
t=0.50, x=0.6065306597
t=1.00, x=0.3678794412
```

The last line agrees with the hand prediction. The result is printed in the
terminal; this small script does not create a plot or save a result file.

## Change the model

In `decay.eqi`, change just the rate declaration to:

```eqiora
parameter rate: 1 / s = 2;
```

Before rerunning, predict $x(1)=\exp(-2)\approx0.135335$: doubling the rate makes
the quantity decay faster. Run the **same command and script** again. Its last
line should now be close to `t=1.00, x=0.1353352833`.

You changed the model, not the time method. Restore `rate` to 1 when following
the [ODE lesson](/learn/mathematical-modeling/ordinary-differential-equations/).

## Development build

Use a development build only for a feature or result explicitly identified as
newer than the published release. The current [Kármán wake](/gallery/karman-vortex-street/)
video uses changes to equation-derived transport and outlet flux made after
`0.1.2`; reproducing that result requires the linked development revision.

After downloading the [example files](#example-files), install
[Rust stable with Cargo](https://rustup.rs/) and a C compiler/linker. On Ubuntu,
`build-essential` supplies the compiler and linker. Then replace the project's
published dependency with the checkout:

```bash
uv add ./eqiora-source
```

<ExactSourceLink path="examples/decay.eqi" kind="blob">The checked-out revision</ExactSourceLink>
now supplies the installed package. uv records this local source in the project,
so later `uv run` commands keep using it. For this development build, add extras
to the same source, for example `uv add './eqiora-source[gmsh,matplotlib]'`.
Building takes longer than installing a prebuilt wheel.

## If something goes wrong

- **`uv: command not found`:** install uv using its linked instructions, reopen
  the terminal and check `uv --version`.
- **Source build fails:** check `cargo --version` and `cc --version`, then repeat
  the development-build command. Use CPython 3.13 and the checked-out source revision.
- **Wrong Python or missing `eqiora`:** run
  `uv run python -c "import eqiora; print(eqiora.__version__)"` from the project folder.
  For the optional source build, also compare `git -C eqiora-source rev-parse HEAD`
  with the revision in the example-download command; the version alone does not identify it.
- **Model file not found:** keep `decay.eqi` beside `run.py` and run from their
  project folder, or pass its path: `uv run python run.py path/to/decay.eqi`.
- **A source diagnostic:** misspelling `rate` as `missing_rate` in the relation
  produces `EQ0603: unresolved expression symbol`. Correct the
  name to match the declaration. Changing the rate's unit to `m` instead produces
  an addition/subtraction dimension mismatch: the two terms must both have
  inverse-time units.
