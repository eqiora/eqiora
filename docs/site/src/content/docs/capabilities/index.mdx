Browse the problems you can run today, then follow a guide or example for setup
and execution. Eqiora is pre-1.0 software. The
<ExactSourceLink path="docs/capability-matrix.md" kind="blob">capability matrix</ExactSourceLink>
provides detailed implementation, verification, and maturity status.

## At a glance

| Problem family | What you can run |
| --- | --- |
| Scalar PDEs | Cartesian Poisson in 1D–3D and a 2D triangular finite-element example |
| Fluid | 2D steady Stokes flow and a transient Kármán vortex-street example |
| Solid | 2D mixed-boundary linear elasticity |
| Thermal | Temperature transport as a passive scalar |
| Circuits and hybrid systems | A packaged DC motor with a sampled controller |
| Geometry and meshing | Planar geometry construction and Gmsh meshing |
| Differentiation | Parameter derivatives of selected Poisson objectives |
| Execution | Non-stiff scalar first-order ODEs |
| Interfaces | Local source compilation and checking with the CLI |
