A pressure difference drives water through a channel. A moving wall drags it
along. An obstacle redirects the flow and can leave an alternating wake. These
are different consequences of the same mass and momentum balances.

This introductory book starts with predictions you can derive on paper. You
then read their mathematical ingredients in maintained `.eqi` sources, run the
existing cylinder investigation, and learn which conclusions the output supports.

First derive pressure, velocity profiles and time scales on paper. Then run the
steady and transient cylinder examples. The final chapter connects the visible
wake to forces, physical time and quantitative comparison.

## What to bring

Start here if fluid motion is your interest. You need differentiation, elementary
integration and vectors; we explain the stress tensor when it first appears. Use
[quantities and units](/learn/mathematical-modeling/quantities-dimensions-units/)
and [conservation laws](/learn/mathematical-modeling/conservation-laws/) as needed.

For computation, install the published package with [Get started](/get-started/)
and [download the example files](/get-started/#example-files).
Chapter 5 adds the mesh and plotting dependencies to that installation.

## Connections

[Heat transfer](/learn/heat-transfer/) uses the same storage–flux–source
accounting, with energy instead of momentum. Viscosity diffuses momentum;
thermal conductivity diffuses heat. Their coefficients and units differ.
[Structural mechanics](/learn/structural-mechanics/) shares traction and force
balance, but an elastic solid relates stress to displacement strain whereas a
Newtonian fluid relates viscous stress to velocity strain rate.
[Numerical simulation](/learn/numerical-simulation/) develops the error and time
integration ideas used in Chapters 5 and 6.
