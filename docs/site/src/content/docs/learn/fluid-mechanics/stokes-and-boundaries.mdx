## The question

Place a cylinder inside the channel. The flow must turn around it, so the
parallel-flow calculation no longer applies. Which terms should we retain,
and what does the outlet mean physically?

## Compare inertia with viscosity

Choose a speed $U$ and length $L$. Advective inertia scales as $\rho U^2/L$,
while viscous force per volume scales as $\mu U/L^2$. Their ratio is

$$
\mathrm{Re}=\frac{\rho UL}{\mu}=\frac{UL}{\nu}.
$$

At small Reynolds number, for a steady flow, neglecting inertia leaves

$$
-\nabla\cdot\boldsymbol\sigma=\boldsymbol f,
\qquad \nabla\cdot\boldsymbol u=0,
\qquad \boldsymbol\sigma=2\mu\operatorname{sym}(\nabla\boldsymbol u)-p\boldsymbol I.
$$

These are the steady Stokes equations. Small Reynolds number alone does not
justify neglecting rapid temporal changes: on an imposed time scale $T$, the
unsteady-to-viscous ratio is $L^2/(\nu T)$. A rapidly oscillating low-speed flow
may need unsteady Stokes equations.

For a homogeneous Stokes boundary problem driven only by an imposed inlet
velocity, doubling that velocity doubles velocity and pressure; changing
viscosity scales pressure while leaving the velocity solution unchanged.
The traction data must scale consistently. This linearity provides a useful
prediction even when the full spatial field has no simple formula.

The steady example chooses the inlet profile

$$
\boldsymbol u_{\rm in}(y)=\left(\frac{4U_{\max}y(H-y)}{H^2},0\right),
\qquad U_{\max}=0.3\,\mathrm{m/s},\quad H=0.41\,\mathrm m.
$$

From Chapter 3, the mean inlet speed is $0.2\,\mathrm{m/s}$ and the volume flux
per unit span is $0.082\,\mathrm{m^2/s}$. Steady incompressibility requires the
same integrated outlet flux. These values are available before any solve.

At the cylinder and walls, no slip sets $\boldsymbol u=0$. At the outlet,
$\boldsymbol\sigma\boldsymbol n=0$ prescribes a traction. It does **not**
separately impose both $p=0$ and zero velocity gradient. The pressure and viscous
contributions combine to satisfy the one vector condition.

The Stokes model contains no density parameter. It deliberately omits inertia;
entering a large inlet speed does not add that missing term. Use a density and
physical scales to assess applicability before treating a Stokes result as a
prediction for an actual fluid.

### Write the laws directly

To see the mathematics behind the imports, the following handwritten relations
express the unforced interior balance and all four boundary conditions. They use the same
`fluid`, `walls`, fields and viscosity declared above. Keep those declarations and replace the imported instances and `connect`
statements with this block; do not add it beside the imported laws:

```eqiora
relation momentum on fluid {
  -div(
    2 * dynamic_viscosity * symmetric_part(grad(velocity))
    - isotropic_lift(pressure)
  ) = 0;
}
relation incompressibility on fluid {
  div(velocity) = 0;
}
relation inlet_velocity on inlet {
  trace(velocity) = -normal_vector()
    * (4 * inlet_speed * coordinate(1) * (channel_height - coordinate(1))
      / channel_height ^ 2);
}
relation wall_velocity on walls {
  trace(velocity) = 0;
}
relation cylinder_velocity on cylinder {
  trace(velocity) = 0;
}
relation outlet_traction on outlet {
  normal(
    2 * dynamic_viscosity * symmetric_part(grad(velocity))
    - isotropic_lift(pressure)
  ) = 0;
}
```

Here `symmetric_part(grad(velocity))` is $\boldsymbol D$ and
`isotropic_lift(pressure)` is $p\boldsymbol I$. `trace` restricts velocity to
its boundary; `normal` would contract the stress with the outward normal to
write the outlet traction law. The inlet uses the inward normal and the same
parabolic speed as the imported boundary component.

## Pressure gauge: a boundary-dependent question

With prescribed velocity everywhere, adding a constant to pressure changes no
interior pressure gradient. A pressure reference is then needed. A prescribed
traction changes by $-C\boldsymbol n$ under $p\mapsto p+C$; it can fix that
freedom. Do not introduce an extra arbitrary pressure condition without first
checking what the existing boundary laws already determine.

## Exercises

1. Integrate the inlet parabola and recover $0.082\,\mathrm{m^2/s}$.
2. At a right-hand boundary, what velocity direction would the same normal-inlet
   relation prescribe? Explain using its outward normal.
3. Which part of the source changes when a wall moves? Which part changes when
   viscosity depends on shear rate?
4. Why can the steady source not produce a time-evolving vortex street, however
   fine its mesh becomes?

**Check your reasoning.** A right-hand normal inlet points left into the region.
Moving a wall changes a boundary law; non-Newtonian viscosity changes the
constitutive law. Mesh refinement cannot introduce terms absent from the model.
