## Start from a working model

- [Run a model and inspect its result](/guides/run-and-inspect/) — continue the installed decay example, understand the output and change a parameter.
- [How Eqiora fits together](/guides/how-eqiora-fits-together/) — follow Model → realization → run → result and find the right place for each choice.

## Build your workflow

Use the environment and source checkout from Get started for these guides.
Each guide introduces the extra inputs or optional dependencies it needs.

- [Configure Vim, Neovim, or another LSP client](/guides/editors/) — use a released server for diagnostics, hover, formatting and declaration navigation.
- [Create and share a library](/guides/creating-libraries/) — lay out an Eqiora package, import it locally, publish it on GitHub, and lock or vendor its dependencies.
- [Modeling and realization](/guides/modeling/) — author declarations and Eqiora source; bind boundaries, geometry and mesh; resolve packages; configure flow and solid runs.
- [Execution, diagnostics, and arrays](/guides/execution-and-arrays/) — submit and observe a run, inspect structured failures, and handle NumPy and DLPack ownership.
- [Notebook source cells](/guides/notebooks/) — compile Eqiora cells in an IPython kernel using the development extension.
- [Differentiation and framework adapters](/guides/differentiation/) — differentiate a solved field, evaluate parameter batches, and connect PyTorch or JAX.
