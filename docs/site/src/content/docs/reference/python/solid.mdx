## Example: read forces after an elastic solve

Continue with the linear-elasticity `result` from
[modeling](/guides/modeling/):

```python
from eqiora.solid import linear_elasticity_evidence

forces = linear_elasticity_evidence(result)
print(forces.integrated_body_force)
print(forces.constrained_reaction)
```

Each pair gives the x and y components, using the model's two-dimensional
force convention. For a static body loaded only by a body force, the reaction
at the constraints balances the integrated body force.
