An `.eqi` file describes a mathematical model: its quantities, equations, initial
and boundary data, and measurements. Python chooses how to compute with that model.
Use this reference to look up syntax; start with
[Mathematical modeling](/learn/mathematical-modeling/) for the reasoning behind it.

| Write or look up | Reference |
|---|---|
| `model`, `parameter`, `variable`, `state`, `domain`, `observable` | [Declarations](/reference/language/declarations/) |
| Dimensions, SI units, scaled literals, vectors | [Quantities and units](/reference/language/units/) |
| `relation`, `derivative`, `initial`, `law`, `form`, clocks | [Equations and state](/reference/language/equations/) |
| `component`, `instance`, `connect`, `import`, material properties | [Composition](/reference/language/composition/) |
| Electrical, solid, fluid, and sampled-control components | [Standard packages](/reference/standard-packages/) |

## Compile a first model

Save this complete model as `current.eqi`:

```eqi
model Current() {
  parameter voltage: V = 12;
  parameter resistance: Ohm = 4;
  variable current: A;
  relation ohm { voltage = resistance * current; }
  observable measured_current: A = current;
}
```

After [installation](/get-started/), compile it:

```python
import eqiora

model = eqiora.compile(path="current.eqi")
measurement = model.observable("measured_current")
```

The equation determines a current of 3 A. Compilation checks its types and
mathematical structure; [execution](/guides/run-and-inspect/) selects a solver and
produces a Result from which you can read the measurement.

For a time-dependent example, continue with
[ordinary differential equations](/learn/mathematical-modeling/ordinary-differential-equations/).
For exact API signatures, use the [Python reference](/reference/python/).
