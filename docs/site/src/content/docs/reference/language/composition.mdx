## Imports and conserving connections

`import Eqiora.Electrical.Basic.basic as electrical` makes the module's public
declarations available through the local name `electrical`. The project records
the package dependency separately; see [adding a package](/reference/standard-packages/#source-and-installation-boundary).

`connect a, b` joins compatible conserving ports. Across values such as voltage
agree, and signed through values such as current into each component sum to zero.
Thus the divider shares one current around its series loop while the two resistors
have different voltage drops.

Read members using the complete path, for example `upper.positive.current`.
Port compatibility follows the connector declaration, not merely matching member
names or vector sizes. The [electrical walkthrough](/reference/standard-packages/electrical/)
compiles and runs this complete circuit.

## Causal signals

Use `connect output -> input` for a directed signal connection. For example, the
[property-composition project](#material-properties) sends a sampled temperature
to two consumers:

```eqi
connect temperature -> local_flux.temperature;
connect temperature -> slab.temperature;
```

The signal types and clock identities must agree. This wiring carries a value;
it does not apply the flow-conservation rule of a physical connector.

## Binding spatial fields and complete boundaries

A component signature can require a support and an existing field:

```eqi
component UniformTemperature(
  support body: volume(ambient_dimension = 2),
  variable temperature: K on body,
  parameter value: K
) {
  relation uniform on body { temperature = value; }
}

model Square() {
  domain body = box(0, 1, 0, 1);
  variable temperature: K on body;
  instance prescribed: UniformTemperature(
    body = body, temperature = temperature, value = 300[K]
  );
}
```

The component constrains the caller's temperature field; it does not create a
second copy. The same technique lets a volume balance and boundary interface
share one displacement or velocity field.

For a component requiring `complete_exterior(parent = body)`, bind
`exterior = boundaries(left, right, bottom, top)` using every exterior member.
A family member is addressed as `surface.mechanical[boundary = left]`.
See [complete solid and fluid models](/reference/standard-packages/continuum/).

## Material properties

A property contract specifies the inputs, output dimension, and derivative
requirements of a constitutive value. A property release supplies that value
using an analytic expression or a table, together with its validity and attribution.

<Code code={properties.slice(0, properties.indexOf('/// Evaluate signed'))} lang="eqiora" title="A temperature-dependent conductivity" />

The property above accepts temperature in kelvin and returns conductivity in
W/(m·K). Its table uses piecewise affine interpolation over 300–360 K and rejects
values outside that interval. Derivatives are defined inside open segments;
knots and endpoints are excluded from derivative evaluation.

A component requests the contract as `property conductivity: Conductivity`, then
calls it with `conductivity(temperature = temperature)`. The caller binds the
release with `conductivity = Samples`:
