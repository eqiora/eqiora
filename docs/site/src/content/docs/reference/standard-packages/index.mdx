Browse the `.eqi` declarations in the installed source checkout by physical purpose:

| Purpose | Lookup |
|---|---|
| Impose a DC voltage, resistance or electrical reference potential | [Electrical components](/reference/standard-packages/electrical/) |
| Delay a sample or integrate a scalar rate on a supplied clock | [Sampled controls](/reference/standard-packages/controls/) |
| Express a small-strain elastic balance, clamp a boundary or leave it traction-free | [Continuum laws and boundaries](/reference/standard-packages/continuum/#elastic-balance-and-boundaries) |
| Bind density, viscosity, velocity and pressure to an inertial Stokes law | [Inertial flow law](/reference/standard-packages/continuum/#inertial-flow-law) |

Each worked example shows bindings, units and the canonical declaration, and is
checked through the public compiler. For executed problems, see the [gallery](/gallery/).

## Source and installation boundary

[Get started](/get-started/#install-with-uv) creates `eqiora-source` at the exact
revision of these pages and installs it with uv. Its `crates/eqiora-api/packages/` directory holds
the declarations linked below. Run the snippets from the working folder containing
that checkout and your `.venv`.

The examples below compile self-contained declarations from that source tree.
Package-qualified imports additionally require their exact dependency closure;
see [project packages](/guides/modeling/#resolve-and-lock-a-local-package-project).

## Exact property specimens

The <ExactSourceLink kind="blob" path="bindings/python/tests/test_table_property_authoring.py">maintained Python table specimen</ExactSourceLink>
creates a locked local `org.example.PythonTable` package with exact conductivity samples
and separate Fourier-flux and slab-conductance Components. It executes fluxes −24/−32 W/m²
and conductances 1.2/1.6 W/K at 310/340 K and reopens the Model artifact. The
<ExactSourceLink kind="blob" path="crates/eqiora/tests/source_property_tables.rs">Rust source/package specimen</ExactSourceLink>
checks independent secant slopes, validity, knot rejection and authenticated asset closure.
The <ExactSourceLink kind="blob" path="examples/property-composition/README.md">complete local property package</ExactSourceLink>
retains source, table and attribution in the checkout. It drives both Components with live
sampled temperature input, executes table endpoints and interior values, and replays after
moving its vendored lock offline. These are local specimen packages, not bundled standard
releases in `crates/eqiora-api/packages/`. A heated-body Law and transient thermal solve are outside this example.
