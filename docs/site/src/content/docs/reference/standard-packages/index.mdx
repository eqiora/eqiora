## Source and installation boundary

After [installing Eqiora](/get-started/), create a package directory with
`eqiora.toml` and `src/main.eqi`. For example:

```toml title="eqiora.toml"
[package]
name = "org.example.Divider"
version = "0.1.0"
entry = "main"
```

The source imports the desired module:

```eqi
import Eqiora.Electrical.Basic.basic as electrical;
```

Register the bundled dependency, then compile your model by its declaration name:

```python
from pathlib import Path
import eqiora

project = Path("divider")
store = Path("package-store")
store.mkdir(exist_ok=True)
resolution = eqiora.add_bundled_dependency(
    project, store, "Eqiora.Electrical.Basic", version="0.1.0"
)
model = eqiora.compile_package(store, resolution, entry="VoltageDivider")
```

The [electrical example](/reference/standard-packages/electrical/) supplies the
complete `VoltageDivider` model and a solver setup. The bundled dependency operation
writes the project dependency and lock and installs the source into the local store.
Use package imports directly; copying library equations into your model is unnecessary.

To carry a project and its dependencies together:

```python
vendor = project / "vendor"
vendor.mkdir(exist_ok=True)
eqiora.vendor_project(project, store, vendor)
resolution = eqiora.open_project(project, vendor)
model = eqiora.compile_package(vendor, resolution, entry="VoltageDivider")
```

See [project packages](/guides/modeling/#resolve-and-lock-a-local-package-project)
for authoring your own reusable modules and updating a changed project.

The bundled names are `Eqiora.Electrical.Basic`, `Eqiora.Controls.Sampled`,
`Eqiora.Mechanics.Interfaces`, `Eqiora.Solid.LinearElasticity`, and
`Eqiora.Fluid.Incompressible`.

## Thermal components and material properties

These examples are local projects you can reuse and adapt:

- <ExactSourceLink kind="tree" path="examples/heated-body">Heated body</ExactSourceLink>
  contains steady conduction and constant-capacity transient components, complete
  boundary and initial data, and a Python runner. Follow the
  [thermal walkthrough](/learn/heat-transfer/heated-body-in-eqiora/).
- <ExactSourceLink kind="tree" path="examples/property-composition">Property composition</ExactSourceLink>
  contains a temperature-dependent conductivity table, its attribution, and
  Fourier-flux and slab-conductance components that share the property.
  Read the [property syntax](/reference/language/composition/#material-properties).

They are local instructional packages, so resolve their `eqiora.toml` projects
rather than requesting a bundled thermal package.
