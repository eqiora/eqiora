[Standard library](/reference/standard-packages/)

The bundled `Eqiora.Solid.LinearElasticity` and `Eqiora.Fluid.Incompressible`
packages contain reusable volume laws and mechanical boundary interfaces. You
bind your own fields to them and supply a condition on each exterior face. Both
examples below compile as ordinary package imports.

## Elastic balance and boundaries

<Code code={elastic} lang="eqiora" title="elastic-body.eqi" />

The square is clamped on the left and traction-free elsewhere. Its volume load is
zero, so its equilibrium displacement is zero. The Lamé parameters are
`mu = 3 Pa` and `lambda = 2 Pa`. The boundary conditions act on the same
displacement field as the volume equations.

### Elastic components

| Component in `Eqiora.Solid.LinearElasticity.linear_elasticity` | Use |
|---|---|
| `IsotropicBalanceWithPotential2d` | Small-strain isotropic equilibrium with Lamé parameters `mu` and `lambda` |
| `IsotropicMechanicalInterface2d` | Displacement trace and outward elastic traction on the complete exterior |
| `FixedDisplacement2d` | Zero displacement on one face |
| `ZeroTraction2d` | Zero traction on one face |

The balance uses stress $2\mu\varepsilon+\lambda\,\mathrm{tr}(\varepsilon)I$.
`load_potential` is a scalar with units of pressure whose gradient gives the body
force; it is neither a boundary pressure nor a general vector force. The
interface's `QuasistaticMechanicalBoundary` connector pairs displacement with
traction, so a connected terminal shares the body's displacement and carries the
opposite traction.

For plane strain, derive the Lamé parameters from Young's modulus $E$ and
Poisson's ratio $\nu$ as $\mu=E/[2(1+\nu)]$ and
$\lambda=E\nu/[(1+\nu)(1-2\nu)]$. For plane stress, use the effective
in-plane value $\lambda=E\nu/(1-\nu^2)$ instead.

Read [strain and stress](/learn/structural-mechanics/strain-stress/) for the
constitutive derivation and [the mixed-boundary square](/learn/structural-mechanics/mixed-boundary-square/)
for a loaded calculation.

## Steady Stokes flow

<Code code={flow} lang="eqiora" title="stokes.eqi" />

The inlet specifies inward normal speed, the top and bottom walls impose zero
velocity, and the outlet imposes zero total traction. The model contains no
advective or inertial term: use it when viscous stresses dominate.

`SteadyStokesWithPotential2d` supplies momentum balance and incompressibility.
The caller supplies the four boundary relations here. On the left, the outward
normal points left, so the plus sign in the inlet equation gives rightward flow.
At the outlet, `normal(stress) = 0` sets the total traction to zero; it does not
set the pressure to zero.

For port-based boundary composition, the same module supplies
`NewtonianMechanicalInterface2d`, binding `body`, the complete `exterior`,
`velocity`, `pressure`, and `dynamic_viscosity`. Its ports use the
`VelocityTractionBoundary` connector from `Eqiora.Mechanics.Interfaces`.
That package supplies `ZeroVelocity2d` and `ZeroTraction2d` terminal components.
Add it as a direct dependency when importing its declarations into your own source.

[Stokes flow and boundaries](/learn/fluid-mechanics/stokes-and-boundaries/)
derives these conditions. [Computing incompressible flow](/learn/fluid-mechanics/computing-incompressible-flow/)
continues to mesh and solver choices.

## Compile either package example

Save the desired model as `model.eqi`, then create its local project:

```python
from pathlib import Path
import eqiora

project = Path("continuum")
(project / "src").mkdir(parents=True, exist_ok=True)
(project / "src/main.eqi").write_text(Path("model.eqi").read_text())
(project / "eqiora.toml").write_text(
    '[package]\nname = "org.example.Continuum"\nversion = "0.1.0"\nentry = "main"\n'
)
store = Path("package-store")
store.mkdir(exist_ok=True)
resolution = eqiora.add_bundled_dependency(
    project, store, "Eqiora.Solid.LinearElasticity", version="0.6.0"
)
model = eqiora.compile_package(store, resolution, entry="ReferenceElasticBody")
```

For the Stokes example, use `"Eqiora.Fluid.Incompressible"` and entry `"ReferenceStokes"`;
its package version is also `"0.6.0"`. `add_bundled_dependency` installs the
package sources and writes the lock. To run the model, add a mesh and a
numerical method as described in the [modeling guide](/guides/modeling/).

## Inertial flow law

The repository source package `Eqiora.Fluid.InertialStokes` defines the separate
`InertialStokesWithPotential2d` volume component:

<Code code={inertia} lang="eqiora" title="inertial_stokes.eqi — library declaration" />

It binds a velocity state, pressure and force-potential fields, density, and dynamic
viscosity. The time derivative adds inertia; there is still no velocity-advection
term. Supply initial velocity, boundary conditions, pressure reference where needed,
and a time method when building a complete problem around this law.

For a time-dependent advective flow example, see
[cylinder wakes](/learn/fluid-mechanics/cylinder-wakes/).
`Eqiora.Fluid.Incompressible` and `Eqiora.Solid.LinearElasticity` also contain
three-dimensional dynamic volume and interface declarations.

## Other source packages

The repository's `Eqiora.Solid` package has plane-strain and plane-stress
components written in terms of Young's modulus and Poisson's ratio, with typed
material properties and field-driven boundaries. `Eqiora.Fluid` has a combined
steady Stokes component and velocity, pressure, and traction terminals. They are
useful examples of how to combine the underlying equations.

`Eqiora.Solid`, `Eqiora.Fluid`, and `Eqiora.Fluid.InertialStokes` are not bundled,
so `add_bundled_dependency` does not accept them.
