<NotebookStage id="startup-problem" step={1} title="Define the channel and cylinder" emoji="🧭">

Python authors the exact $2.2\,\mathrm{m}\times0.41\,\mathrm{m}$ channel and
subtracts one exact circle. The resulting `Geometry` names the `fluid`, `inlet`,
`outlet`, `walls`, and `cylinder` selections used by meshing, compilation, and
the Result observables.

```python
graph = eqiora.geometry.GeometryGraph()
rectangle = graph.rectangle(x_bounds=(0.0, 2.2), y_bounds=(0.0, 0.41))
circle = graph.circle(center=(0.2, 0.2), radius=0.05)
fluid = graph.subtract(rectangle, circle)
geometry = graph.build(fluid, named_topology={...})
```

<NotebookStage id="startup-model" step={2} title="Eqiora model definition" emoji="🧩">

The `.eqi` source defines transient incompressible Navier–Stokes equations
and the support names to bind to the geometry.
With velocity $\boldsymbol{u}$, density $\rho$, stress
$\boldsymbol{\sigma}$, and force potential $\phi$, the momentum and
incompressibility relations are

$$
\rho\,\partial_t\boldsymbol{u}
+ \rho\,\nabla\!\cdot(\boldsymbol{u}\otimes\boldsymbol{u})
- \nabla\!\cdot\boldsymbol{\sigma}
- \nabla\phi = 0,
\qquad
\nabla\!\cdot\boldsymbol{u}=0.
$$

<NotebookStage id="startup-mesh" step={3} title="Planning, then mesh generation" emoji="🔷">

Set the Gmsh characteristic-size target. `resolve` plans the mesh;
`generate` executes Gmsh and returns it.

```python
request = eqiora.meshing.GmshMesher(
    maximum_boundary_error=1e-4,
    maximum_target_size=0.025,
    minimum_mean_ratio=1e-5,
    maximum_boundary_facets=50,
)
mesh_plan = eqiora.meshing.resolve(geometry, request)
mesh = eqiora.meshing.generate(mesh_plan)
```

<Aside type="caution" title="Choosing a mesh size">

`0.025 m` is a Gmsh characteristic target, rather than the guaranteed length
of every edge. Refine the mesh and time step before drawing quantitative
conclusions from this short run.

</Aside>

</NotebookStage>

<NotebookStage id="startup-run" step={4} title="Run ten time steps" emoji="▶">

A steady MINI/P1 result supplies the nonzero initial state. Combine the transient
model with MINI/P1 elements, Backward Euler time stepping, Newton iteration,
and linear-solve and scaling settings. Save ten startup outputs at $\Delta t=0.01\,\mathrm{s}$.

```python
plan = eqiora.resolve(
    model,
    mesh=mesh,
    spatial=eqiora.fem.MiniP1(),
    temporal=eqiora.time.BackwardEuler(0.01),
    solve=eqiora.solve.Newton(linear=linear),
    scaling=eqiora.fluid.IncompressibleScaling(...),
)
result = eqiora.run(
    plan,
    state=state,
    steps=10,
    output_steps=tuple(range(1, 11)),
)
```

<NotebookStage id="startup-observables" step={5} title="Inspect vorticity, force, and pressure" emoji="📐">

At the final time step, calculate cell-average vorticity, the signed
two-dimensional cylinder force, and pressure samples at the front and rear
of the cylinder. Pressure samples use continuous-P1 interpolation.

```python
accepted = result.trajectory.state(10)
vorticity = accepted.curl(plan.capability.velocity)
cylinder_force = accepted.boundary_force(geometry.selection("cylinder"))
front_pressure = accepted.sample(plan.capability.pressure, at=(0.15, 0.2))
rear_pressure = accepted.sample(plan.capability.pressure, at=(0.25, 0.2))
```
