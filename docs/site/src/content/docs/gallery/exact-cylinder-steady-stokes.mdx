Build a two-dimensional steady Stokes flow model, generate a mesh, and plot
pressure around a cylinder. Connect its pressure field to the balance of
viscous stress and pressure, then explore how the mesh affects the result.

## Before you begin

Follow [Get started](/get-started/#example-files) and keep its `eqiora-source` checkout and
`.venv`. From the folder containing both, add the mesh and plotting extras,
then run the example with the same Python environment:

```bash
uv add 'eqiora[gmsh,matplotlib]'
uv run python eqiora-source/examples/python/exact_cylinder_stokes.py --pressure-png pressure.png
```

<NotebookStage id="problem-setup" step={1} title="Problem setup" emoji="🧭">

The fluid region is a $2.2\,\mathrm{m} \times 0.41\,\mathrm{m}$ channel with an
exact authored circle centred at $[0.2, 0.2]\,\mathrm{m}$ and radius
$0.05\,\mathrm{m}$. The problem is two-dimensional, steady, incompressible
Stokes flow.

The Python composition authors that geometry explicitly:

```python
geometry_graph = eqiora.geometry.GeometryGraph()
rectangle = geometry_graph.rectangle(x_bounds=(0.0, 2.2), y_bounds=(0.0, 0.41))
circle = geometry_graph.circle(center=(0.2, 0.2), radius=0.05)
fluid = geometry_graph.subtract(rectangle, circle)
geometry = geometry_graph.build(
    fluid,
    named_topology={
        "fluid": fluid.region,
        "inlet": rectangle.boundaries[0],
        "outlet": rectangle.boundaries[1],
        "walls": rectangle.boundaries[2:],
        "cylinder": circle.boundaries[0],
    },
)
```

<NotebookStage id="model-definition" step={2} title="Eqiora model definition" emoji="🧩">

Start with the Cauchy stress. With velocity $\boldsymbol{u}$, pressure $p$, dynamic viscosity
$\mu$, identity tensor $\boldsymbol{I}$, and force potential $\phi$:

$$
\boldsymbol{\sigma}(\boldsymbol{u},p)
= 2\mu\,\operatorname{sym}(\nabla\boldsymbol{u}) - p\boldsymbol{I}
$$

$$
-\nabla\!\cdot\boldsymbol{\sigma}(\boldsymbol{u},p)-\nabla\phi=0,
\qquad
\nabla\!\cdot\boldsymbol{u}=0
$$

Here $\mu=0.001\,\mathrm{kg}/(\mathrm{m}\,\mathrm{s})$,
$\phi=0\,\mathrm{Pa}$, and pressure has source unit
`kg/(m*s^2)`, displayed as pascals. The equations below express this model in Eqiora.

Compile the component with the geometry used for meshing:

```python
model = eqiora.compile(
    path=files(eqiora).joinpath("examples", "steady-flow-past-cylinder.eqi"),
    geometry=geometry,
    entry="SteadyFlowPastCylinder",
    bindings={
        "fluid": geometry.selection("fluid"),
        **{
            side: (geometry.selection(side), geometry.selection("fluid"))
            for side in ("inlet", "outlet", "walls", "cylinder")
        },
        "dynamic_viscosity": 1.0e-3,
        "zero_pressure": 0.0,
        "inlet_speed": 0.3,
        "channel_height": 0.41,
    },
)
```

<NotebookStage id="mesh-and-boundaries" step={3} title="Mesh and boundaries" emoji="🔷">

The inlet profile uses $U_{\max}=0.3\,\mathrm{m}/\mathrm{s}$ and channel
height $H=0.41\,\mathrm{m}$:

$$
g(y)=\frac{4U_{\max}y(H-y)}{H^2},
\qquad
\boldsymbol{u}_{\mathrm{in}}=[g(y),0]
$$

At the outlet, $\operatorname{normal}(\boldsymbol{\sigma})=0$. The walls and
cylinder use $\boldsymbol{u}=0$.

The full source above attaches these relations to `fluid`, `inlet`, `outlet`,
`walls`, and `cylinder`. At the left inlet, the outward normal points left,
so `trace(velocity) + normal(isotropic_lift(inlet_profile)) = 0` directs flow
into the channel. The outlet law balances pressure and viscous traction together;
it does not separately prescribe zero pressure and zero velocity gradient.

Request at most 50 circular-boundary facets, then generate the mesh:

```python
mesh_request = eqiora.meshing.GmshMesher(
    maximum_boundary_error=1e-4,
    maximum_target_size=0.025,
    minimum_mean_ratio=1e-5,
    maximum_boundary_facets=50,
)
mesh_plan = eqiora.meshing.resolve(geometry, mesh_request)
mesh = eqiora.meshing.generate(mesh_plan)
```

<Aside type="note" title="Mesh size">

Gmsh 4.15.2 generates straight-edged elements with a global target size of
0.025 m. The boundary-error and facet settings control the circle approximation;
the target size does not guarantee the length of every edge.

</Aside>

<NotebookStage id="submit-and-result" step={4} title="Submit and result" emoji="▶">

Combine the `Model` and `Mesh` with the MINI/P1 element and linear-solve
settings. Scaling is derived when `scaling=None`. Run the resulting `Plan`
to obtain a `Result`.

```python
linear = eqiora.solve.Linear(
    algorithm=eqiora.solve.LinearSolver.SparseLu,
    preconditioner=eqiora.solve.Preconditioner.Identity,
    reduction=eqiora.solve.Reduction.Fast,
    provider=eqiora.solve.SolverProvider.faer(),
    relative_tolerance=1e-6,
    absolute_tolerance=1e-13,
    maximum_iterations=10_000,
)
plan = eqiora.resolve(
    model,
    mesh=mesh,
    spatial=eqiora.fem.MiniP1(),
    solve=linear,
    scaling=None,
)
result = eqiora.run(plan)
```
