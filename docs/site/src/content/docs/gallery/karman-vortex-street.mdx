<NotebookStage id="wake-problem" step={1} title="Define the channel and cylinder" emoji="🧭">

Python authors the exact $2.2\,\mathrm{m}\times0.41\,\mathrm{m}$ channel and
subtracts a circle of diameter $0.1\,\mathrm{m}$ centered at
$(0.2\,\mathrm{m}, 0.2\,\mathrm{m})$. The `Geometry` names the `fluid`,
`inlet`, `outlet`, `walls`, and `cylinder` selections used throughout the run.

```python
graph = eqiora.geometry.GeometryGraph()
rectangle = graph.rectangle(x_bounds=(0.0, 2.2), y_bounds=(0.0, 0.41))
circle = graph.circle(center=(0.2, 0.2), radius=0.05)
fluid = graph.subtract(rectangle, circle)
geometry = graph.build(fluid, named_topology={...})
```

<NotebookStage id="wake-model" step={2} title="Set the flow problem" emoji="🧩">

The `.eqi` source defines transient incompressible Navier–Stokes equations,
no-slip walls and cylinder, a parabolic inlet, and an open outlet. The physical
setup uses density `1 kg/m³`, dynamic viscosity `0.001 Pa·s`, and maximum inlet
speed `1.5 m/s`. With mean inlet speed `1 m/s` and cylinder diameter `0.1 m`,
the Reynolds number is $\mathrm{Re}=\rho\bar U D/\mu=100$.

<ExactSourceLink path="examples/transient-flow-past-cylinder.eqi" kind="blob">Open the Eqiora source</ExactSourceLink>

</NotebookStage>

<NotebookStage id="wake-mesh" step={3} title="Generate the mesh" emoji="🔷">

The workflow asks Gmsh for an unstructured triangular mesh while retaining the
exact named geometry needed for boundary conditions and observations. Its
characteristic-size target is $h=0.02\,\mathrm{m}$.

```python
request = eqiora.meshing.GmshMesher(
    maximum_boundary_error=1e-4,
    maximum_target_size=0.02,
    minimum_mean_ratio=1e-5,
    maximum_boundary_facets=50,
)
mesh = eqiora.meshing.generate(eqiora.meshing.resolve(geometry, request))
```

Mesh and time-step refinement are required before treating derived quantities
as quantitative benchmark results.

</NotebookStage>

<NotebookStage id="wake-run" step={4} title="Advance the wake" emoji="▶">

The resolved plan combines MINI/P1 elements, Backward Euler time stepping,
Newton iteration, a sparse linear solver, and incompressible-flow scaling. The
workflow retains selected states so the wake can be inspected over time.

```python
plan = eqiora.resolve(
    model,
    mesh=mesh,
    spatial=eqiora.fem.MiniP1(),
    temporal=eqiora.time.BackwardEuler(0.01),
    solve=eqiora.solve.Newton(linear=linear),
    scaling=eqiora.fluid.IncompressibleScaling(...),
)
result = eqiora.run(plan, state=state, steps=steps, output_steps=output_steps)
```

<NotebookStage id="wake-observables" step={5} title="Inspect vorticity and loads" emoji="📐">

Cell-average curl exposes the rotating structures convected behind the
cylinder. The same accepted states provide signed cylinder force and pressure
samples at the front and rear of the obstacle.

```python
accepted = result.trajectory.states[-1]
vorticity = accepted.curl(plan.capability.velocity)
cylinder_force = accepted.boundary_force(geometry.selection("cylinder"))
front_pressure = accepted.sample(plan.capability.pressure, at=(0.15, 0.2))
rear_pressure = accepted.sample(plan.capability.pressure, at=(0.25, 0.2))
```
