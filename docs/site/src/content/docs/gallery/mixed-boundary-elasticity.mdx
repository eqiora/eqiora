Model a two-dimensional linear-elastic square with a fixed left edge and
traction-free remaining edges, then compare its original and deformed mesh.

## Before you begin

Follow [Get started](/get-started/#example-files) and keep its `eqiora-source` checkout and
`.venv`. From the folder containing both, add plotting support and save the
computed displacement:

```bash
uv add 'eqiora[matplotlib]'
uv run python eqiora-source/examples/python/mixed_boundary_elasticity.py --displacement-png displacement.png
```

<NotebookStage id="elasticity-problem" step={1} title="Problem and boundaries" emoji="🧱">

Create a $1\,\mathrm{m}\times1\,\mathrm{m}$ rectangle.
The left edge has zero displacement; the right, lower, and upper edges have
zero traction. A $16\times16$ Cartesian mesh realizes the domain.

```python
graph = eqiora.geometry.GeometryGraph()
rectangle = graph.rectangle(x_bounds=(0.0, 1.0), y_bounds=(0.0, 1.0))
geometry = graph.build(
    rectangle,
    named_topology={
        "body": rectangle.region,
        "x_lower": rectangle.boundaries[0],
        "x_upper": rectangle.boundaries[1],
        "y_lower": rectangle.boundaries[2],
        "y_upper": rectangle.boundaries[3],
    },
)
```

<NotebookStage id="elasticity-model" step={2} title="Eqiora model definition" emoji="🧩">

The `.eqi` component defines displacement, material parameters, load potential,
equilibrium, the body support and its four boundary supports. With displacement
$\boldsymbol{u}$, shear modulus $\mu$, Lamé coefficient $\lambda$, and length
$\ell$, its stress and load are

$$
\boldsymbol{\sigma}(\boldsymbol{u})
=2\mu\,\operatorname{sym}(\nabla\boldsymbol{u})
+\lambda\,\operatorname{div}(\boldsymbol{u})\boldsymbol{I},
\qquad q=\frac{2\mu x}{\ell}.
$$

The balance relation is

$$
-\nabla\!\cdot\boldsymbol{\sigma}(\boldsymbol{u})-\nabla q=0.
$$

<NotebookStage id="elasticity-plan" step={3} title="Choose numerical settings" emoji="🔷">

Compile the model, then select Q1 elements and linear-solve settings.

```python
model = eqiora.compile(
    path=files(eqiora).joinpath("examples", "mixed-boundary-elasticity.eqi"),
    geometry=geometry,
    entry="MixedBoundaryElasticity2d",
    bindings={
        "body": geometry.selection("body"),
        **{
            side: (geometry.selection(side), geometry.selection("body"))
            for side in ("x_lower", "x_upper", "y_lower", "y_upper")
        },
        "mu": 3.0, "lambda": 0.0, "length_scale": 1.0,
    },
)
plan = eqiora.resolve(
    model,
    mesh=mesh,
    spatial=eqiora.fem.Q1(),
    solve=eqiora.solve.Linear(...),
)
```

<NotebookStage id="elasticity-result" step={4} title="Run and inspect displacement" emoji="▶">

The example function runs the plan and returns it with the result:

```python
return plan, eqiora.run(plan)
```

Select the displacement field:

```python
displacement = result.output(plan.capability.displacement)
```

The plotting path reuses that function; it does not restate geometry, physics,
mesh generation, or solve policy.

</NotebookStage>

does not make this a large-deformation material model.
