lists each capability with its implementation status and, separately, its verification status.
Use it to find the checks behind a particular feature.

## External comparisons

The [Poisson comparison with FEniCSx](/evidence/poisson-fenicsx/) reports
accuracy, ordinary execution, preparation and memory for one single-threaded
2D Q1 workload. It retains Eqiora's slower execution result and states the
measurement boundaries and remaining comparisons. The separate
[3D Q1 comparison](/evidence/poisson-fenicsx-3d/) reports three cube meshes
on a busy shared CPU, including the slower Eqiora observations and SMT load.

## Find the source

The <ExactSourceLink path="verify" kind="tree">case manifests</ExactSourceLink>
name each registered claim, its reference, and its executable target. Read the
case's README for assumptions and required environment. Ordinary product tests
remain beside the code they exercise.

## Run a selected check

From a repository checkout, list the current case-to-capability mapping:

```bash
cargo run -p eqiora-verify -- index
```

Then run the case you need, for example:

```bash
mise run fast -- --case interfaces.cli-compile-check
```

A passing case supports only its stated claim in its stated environment, and an
implemented capability is not necessarily independently verified. See
<ExactSourceLink path="docs/development/local-verification.md" kind="blob">local verification</ExactSourceLink>
for focused checks and environment requirements.
