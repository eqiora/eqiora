## Python parity: can the complete model be built in Python?

Python can compile Eqiora source and author models with `eqiora.Module`, including
Components, Fields, Parameters, units, clocks, and equations. Geometry and mesh
objects are supplied when resolving spatial problems. Available execution paths
include scalar PDEs, elasticity, steady Stokes flow, selected transient flow,
ODEs, and FSI examples. The table below distinguishes authoring from execution
and lists the remaining gaps. See the [modeling guide](../python/modeling.md) for
current examples.
