# Reference basis

The independent reference is the explicit displacement polynomial and Q1 midpoint
sums, elementary Q1 stiffness integrals, and stationary energy identities in
[expected](../expected/README.md). The base mixed-boundary material,
traction and load conventions are also exercised by
[`solid.mixed-boundary-elasticity-2d`](../../mixed-boundary-elasticity-2d/README.md).
No implementation-produced energy or stored package digest defines the oracle.
