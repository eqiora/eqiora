# Expected-value owner

Fixed sine budgets and finite-grid expectations are defined in the
[independent reference](../reference/README.md). Polynomial coefficient, residual
and reaction allowances are defined in the [rational oracle](../reference/POLYNOMIAL.md).
The [saved-result replay](../README.md#saved-results-and-reproduction) checks
original observations against those unchanged owners. Observed output is not an
expected-value source.
