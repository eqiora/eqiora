# Expected results

Expected temperatures and physical boundary functionals are generated by the
canonical [reference owner](https://github.com/eqiora/eqiora/blob/c7add4f8be40f3dcd5333542c37bba99cdf743f1/verify/numerics/cartesian-robin-q1/reference/README.md),
independently of Eqiora results. The intended result-only checks use E, the
reference residual bound and predeclared Q1 bounds for integrated Fourier heat,
right-face temperature and convective heat. No private nodal weak reactions,
Eqiora coefficients, matrix or load are stored as expected values here.
