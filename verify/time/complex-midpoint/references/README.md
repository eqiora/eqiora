# Independent reference

The continuous solution follows by differentiating exp(i t): z_j(t)=j exp(i t),
with (u,v)=3(cos(t),sin(t)). Premultiplication by the invertible stated mass matrix
does not change this solution.

The discrete and interpolation expectations are algebraic derivations in
[../expected/README.md](../expected/README.md). They do not use values sampled
from the implementation or fit a tolerance to a run.
