# Atomic retained stochastic continuation

The positive path admits the ordinary common Plan and Run request, then compares
uninterrupted execution with a freshly reconstructed Run at every saved boundary.
Both Ito Euler-Maruyama and constant-rate pure Poisson paths use the same original
horizon and accepted partition. A larger trial is deliberately evaluated and
discarded before each accepted step. The checkpoint must remain byte-identical
across that rejection, and reopened physical state and retained path state must
match the uninterrupted path. Poisson probes independently count retained arrivals
and check right-continuity and preservation of the pending threshold.

Reidentified mutants recompute their envelope digest so that rejection must reach
the named semantic gate: changed occurrence lineage, sampler or target; missing
paths or pending thresholds; non-increasing or non-dyadic partition; changed physical
state; or a skipped requested output. Truncated bytes, unknown profiles, a foreign
original horizon, and an unfinished checkpoint relabelled as a complete Trajectory
also reject. A physical State alone does not attest its stochastic continuation.

Exact replay assumes the same sampler version, binary64 precision, partition, and
native runtime/libm environment. Stored target metadata is necessary but cannot
prove equivalence of arbitrary machines or libraries. This case does not claim
cross-environment identity, changed-partition solver identity, adaptive SDE error
control, dynamic-intensity jumps, or installed-wheel execution. The ordinary native
public lifecycle and the installed Python separate-process test cover those client
boundaries separately, without widening this claim.
